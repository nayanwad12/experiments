# Delivery Checklist
Run this before every delivery. It's what makes you look like a studio.

## Picture
- [ ] Contact sheet of the **final file** reviewed (not just the draft)
- [ ] First frame strong (no black frame, no blink)
- [ ] No typos; names and prices exactly as given
- [ ] Text inside safe zones, nothing touching the edges
- [ ] Brand colours and fonts only
- [ ] Captions readable, not covering faces

## Sound
- [ ] Voice clear on phone speakers and headphones
- [ ] Music under the voice, ends cleanly
- [ ] Loudness −14 LUFS (social) / −16 (podcast, web)

## Files
- [ ] Every requested platform exported
- [ ] Names: `client_project_format_v#.mp4`
- [ ] `.srt` subtitles included
- [ ] Thumbnail/cover still included
- [ ] Previous versions kept (not overwritten)

## Message to the client
- [ ] Download link + what's inside
- [ ] Contact sheet attached
- [ ] 1–3 specific questions or "approved?" ask
- [ ] Licence notes (music generated original, fonts OFL, footage source)
