# Glossary A–Z

| term | meaning |
|---|---|
| **Alpha / transparency** | an invisible background so graphics can sit on top of other video |
| **Anchor** | the point a crop or zoom keeps centred (usually the face) |
| **Aspect ratio** | frame shape: 9:16 vertical, 16:9 horizontal, 1:1 square, 4:5 portrait |
| **B-roll** | supporting footage shown over the main speaker |
| **Bar** | 4 beats of music; the natural place for cuts |
| **Beat table** | a time-by-time plan of picture, sound and text |
| **Boil** | the gentle wobble of hand-drawn/clay outlines between drawings |
| **BPM** | beats per minute (music tempo) |
| **Brief** | the written plan: goal, audience, platform, vibe, brand |
| **Clean plate** | the background with the person removed |
| **Contact sheet** | a grid of frames used to review a video at a glance |
| **CTA** | call to action: what you want the viewer to do |
| **Cut-down** | a shorter version of an edit (15 s, 6 s) |
| **Ducking** | lowering music automatically while someone speaks |
| **Ease-out** | fast start, gentle stop: the default for things arriving |
| **Easing** | how motion speeds up/slows down (ease-out, back, bounce…) |
| **EDL** | edit decision list: which parts of the source are kept, in what order |
| **ffmpeg** | the engine that cuts, encodes and exports video |
| **FPS** | frames per second (24 cinematic, 30 social, 60 smooth) |
| **Forced alignment** | matching each word of a transcript to its exact time |
| **Grade** | the colour look of a video |
| **Hook** | the first 1–3 seconds that stop the scroll |
| **Jump cut** | a cut within the same shot (removing a pause) |
| **Ken Burns** | a slow pan/zoom over a still photo |
| **Kinetic typography** | animated text as the main visual |
| **Letterbox** | black bars top and bottom for a cinematic look |
| **Lower-third** | a name/title graphic in the lower part of the frame |
| **LUFS** | loudness unit; social platforms target about −14 LUFS |
| **LUT** | a file that applies a colour look |
| **Matte** | a black-and-white mask showing where the subject is |
| **On twos** | holding each drawing for 2 frames for a handmade feel |
| **Optical flow** | creating in-between frames for smooth slow motion |
| **Punch-in** | a zoom on a jump cut to add energy |
| **Render** | turning the edit into a finished video file |
| **Safe zone** | the area where platform buttons won't cover your text |
| **SFX** | sound effects |
| **Skill** | a ready-made playbook + tools Claude uses for a type of task |
| **.srt** | a subtitle file uploaded alongside a video |
| **Stills** | single check frames rendered before the full video |
| **Style frame** | a still that defines the look of a section before animating |
| **Template** | a reusable project you fill with new text/data |
| **Transcript** | the text of everything said, with timestamps |
| **TTS** | text-to-speech (AI voiceover) |
| **Vibe Loop** | Brief → Beat table → Build → Stills → Draft → Final → Export |
