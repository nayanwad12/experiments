# Feedback Phrasebook: Get It Fixed in One Round
Formula: **WHERE** (timestamp) + **WHAT** (element) + **HOW** (direction).

## Instead of… say…
| ❌ vague | ✅ precise |
|---|---|
| make it better | the hook needs more energy: faster cut at 0:01 and an impact sound |
| the text is off | at 0:04 the title overlaps my face, so move it up 10% |
| timing feels weird | at 0:06.2 the chip lands a beat late, so put it on the beat |
| more pop | bigger captions, highlight colour lime, add a pop sound on each word |
| it's boring | cut 0:08–0:12, it repeats the point; add a zoom at 0:15 |
| colours are wrong | use only #0B0B0D and #D4FF3F, remove the blue |
| music is too much | music 4 dB quieter and duck it more under my voice |
| make it premium | slower moves, more empty space, serif titles, no bounces |
| the end is weak | hold the end card 1 s longer and add a sparkle on the CTA |

## Useful phrases
- "Show me stills at 0:02, 0:07 and 0:15 before re-rendering."
- "Change only X, keep everything else exactly the same."
- "Give me two options for the hook so I can choose."
- "Undo the last change." / "Go back to version 2 for the music."
- "Log these changes in revisions.md."

## Batch your notes
Send small fixes together in one message, numbered. Send a big direction change on its own.
