# Hook Swipe File: 50 Scroll-Stopping Openers
The first 2 seconds decide everything. Each hook works muted: big text + motion + contrast.
Format: **on-screen text** · *visual idea*

## Bold claims (1–10)
1. **I made 10 reels in 1 hour** · *a timer racing, reels stacking up*
2. **Editing is dead. Directing is in.** · *a timeline crumpling into a ball*
3. **This took me 4 minutes** · *the finished video slamming in*
4. **No timeline. No keyframes.** · *keyframes popping like bubbles*
5. **AI edited this entire video** · *split screen raw vs final*
6. **Your editor hates this trick** · *a big red stamp*
7. **The fastest way to make reels in 2026** · *a speedometer maxing out*
8. **I stopped using Premiere** · *a software logo sliding off screen*
9. **One sentence. One finished ad.** · *a typed prompt, then the ad plays*
10. **This is what ₹0 music sounds like** · *waveform bursting on the beat*

## How to test hooks
- Make 2–3 versions that differ ONLY in the first 3 seconds.
- Post at the same time on different days, or run them as ad variants.
- Keep the winner's *pattern*, not just its words.
