# Sound Design Cheat Sheet

## Music moods
| mood | BPM | key feel | best for |
|---|---|---|---|
| upbeat | 118 | major, plucks | creators, tutorials |
| hype | 128 | minor, pumping | ads, reveals, sport |
| tech | 124 | minor, driving | SaaS, AI, product |
| corporate | 110 | major, light | brand, LinkedIn, explainer |
| chill | 84 | lo-fi, 7th chords | vlogs, calm talking heads |
| cinematic | 72 | minor pads, hits | brand films, trailers |
| playful | 120 | glockenspiel | kids, food, fun |

## Beat math
**beat = 60 ÷ BPM · bar = 4 beats.** Cut on bars, accent on beats. Pick the BPM so the video is a whole number of bars.

## SFX: when to use
| sfx | moment |
|---|---|
| whoosh / swish | transitions (start 0.3 s before the cut) |
| pop | text, stickers, chips appear |
| impact / bass drop | hook, reveal, title slam |
| riser / downlifter | build into / out of a big moment |
| click / typing | UI, prompts, buttons |
| tick | timers, counters |
| sparkle / ding | magic, success, notification |
| glitch | errors, digital transitions |
| shutter | photos, freeze frames |

## Levels
| element | level |
|---|---|
| voice | 0 dB reference |
| music under voice | −8 to −12 dB, ducked a further ~10 dB while speaking |
| SFX | −6 to −12 dB (impacts up to −3) |
| final master | **−14 LUFS** social · **−16 LUFS** podcast/web · peaks under −1 dB |

## Licensing
Generated music/SFX = yours. Client tracks = licensed only. Never put platform-library music in client deliverables.
